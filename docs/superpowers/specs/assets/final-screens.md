# Carrum Voice — final screens (Simple, light + dark)

## Shared design system text (designMd) — use for BOTH modes, only colorMode/colours differ

Carrum Voice — a calm, simple console for an ops team running Hindi/Hinglish AI calling agents. Clean and simple beats dense.

Simplicity rules:
- Readable sizes: body 15-16px, labels 13-14px, never below 13px. Page titles 22-24px weight 500.
- At most TWO columns of content per screen (main + one side panel). No third rail.
- 24px page gutter, 16px between rows, controls 40px tall.
- Tables: 6 columns max, horizontal rules only, no outer card.
- Plain words ('Outcome' not 'Disposition', 'Steps' not 'Nodes'). Hide technical details (ids, token/chunk counts, version numbers, latency, system status).
- Advanced settings behind an 'Advanced' disclosure; secondary actions in a '…' menu.
- Hanken Grotesk for everything; JetBrains Mono ONLY for phone numbers, times and durations.
- Sentence-case labels, never ALL CAPS, never letter-spaced. No middle-dot '·' joined strings. No decorative status dots. No cards inside cards. No emoji icons; thin line icons. No gradients, no shadows, no purple/indigo.
- Never invent prices, offers, payouts or system claims. Prices show '₹—'.
- Exactly ONE amber primary button per screen (fill #F2B544, text #2A1F0B).
- AMBER = a person (caller, operator, current step). COOL BLUE = the agent and system values.
- Expression chips: inline lowercase chips in scripts: [happy] [laugh] [sad] [fear] [angry] [whisper] [pause 1.2s] [excited] — each its own muted tint + 1px border + darker (light mode) / lighter (dark mode) text of the same hue (orange for happy/laugh, blue-violet sad, plum fear, red angry, grey whisper, slate pause, pink excited).
- Shell: left sidebar 232px: workspace "Carrum Mobility", Dashboard, Agents, Workflows, Knowledge base, Live calls (chip "3"), Call history, Integrations ('Soon' chip), Settings; user "Kapil Rohilla" at the bottom with a light/dark toggle. Top bar: title/breadcrumb left, one primary action right.

LIGHT tokens: page #FBF9F5, panels #FFFFFF with 1px #E4DFD6 border, wells/inputs #F3F0EA, sidebar #F3F0EA, strong rule #CFC8BC, ink #1E1A16, secondary ink #4A443D, muted #6E675F, amber TEXT #9A6200 on tint #FBEFD6, cool blue #2F6DB5 on #E6EEF8, ok #2E7D4F on #E5F3EA, bad #B4412F on #F9E4E0.

DARK tokens (same hues re-derived, never inverted): page #1E2228, panels #262B32 (lighter than page) with 1px #3A4049, wells/inputs #14171B, sidebar #191C21, strong rule #545C67, ink #EEF0F3, secondary #C9CED6, muted #A3AAB5, amber text #F2B544 on #4A3A1C, cool blue #7FB2F0 on #1F3248, ok #6FCF8E on #1F3326, bad #F07A6A on #3A2220.

Design system settings: headlineFont/bodyFont/labelFont HANKEN_GROTESK, roundness ROUND_EIGHT, customColor #F2B544, colorVariant NEUTRAL, overridePrimaryColor #F2B544. Light: colorMode LIGHT, overrideSecondaryColor #2F6DB5, overrideNeutralColor #FBF9F5. Dark: colorMode DARK, overrideSecondaryColor #7FB2F0, overrideNeutralColor #1E2228.
